# Vue Component Story Format

This Storybook addon allows you to write Storybook stories using Vue single file components instead of ESM that regular CSF is based on.

## Features

- **Native Vue syntax** - Write stories as Vue components
- **Args support** - Define story variants with args objects
- **Type safety** - Full TypeScript support with `defineProps`
- **Automatic transformation** - Props automatically bind to Storybook args

## Requirements

- Vue 3.5+
- Storybook 10+
- Vite 7+
